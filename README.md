# README - Supply Chain Issues Project Submission

## 1. Submission Overview

This submission contains the completed deliverables for the Supply Chain Issues project. The work addresses critical supply chain disruptions affecting FDA compliance, including email analysis, issue review, meeting coordination, action planning, supply chain risk analysis, mitigation recommendations, and a stakeholder presentation.

Each task includes the required Copilot prompts used during the project, along with the final outputs generated for review.

## 3. Task Overview and Deliverables

### Task 1: Problem Identification and Action Prioritization

This task focused on identifying the most critical supply chain issues from the provided email and translating them into actionable insights.

Deliverables include:

- Copilot prompt used to summarize the email.
- Summarized email analysis.
- Copilot prompt used to generate the Supply Chain Issues Review report.
- Final Supply Chain Issues Review report.

The final report includes the required sections:

- Introduction
- Outline of the Business Problem
- Action Items
- Conclusion

---

### Task 2: Cross-Functional Meeting Coordination and Action Planning

This task focused on coordinating a cross-functional meeting and converting meeting content into a structured action plan.

Deliverables include:

- Copilot prompt used to generate the meeting invite and agenda.
- Meeting invite printout.
- Copilot prompt used to generate action items.
- Final Supply Chain Issues Review Action Plan.

The action plan is organized into:

- General Strategies
- Immediate Actions
- Short-Term Actions (1-3 weeks)
- Ongoing Actions

---

### Task 3: Supply Chain Risk Analysis and Mitigation Strategies

This task focused on analyzing supply chain data and developing a risk assessment report.

Deliverables include:

- Copilot prompt used for the Excel analysis.
- Supply Chain Report analysis output.
- Copilot prompt used to generate the Supply Chain Issue Analysis Report.
- Final Supply Chain Issue Analysis Report.

The report includes:

- Executive Summary
- Component Overview
- Implications for Compliance
- Root Cause Analysis
- Mitigation Strategies

---

### Task 4: Stakeholder Report Creation and Presentation

This task focused on creating a professional stakeholder presentation that reflects the findings from the Supply Chain Issue Analysis Report and the Supply Chain Report data.

Deliverables include:

- Final Supply Chain Issue Compliance Report presentation.
- Copilot prompt used to generate the presentation.

The presentation includes:

- Professional design
- Consistent formatting
- Speaker notes

## 4. How to Navigate and Review the Submission

1. Start by reviewing the files in numerical task order, beginning with Task 1 and ending with Task 4.
2. For each task, review the Copilot prompt file first to understand how the deliverable was generated.
3. After reviewing the prompt, open the corresponding final deliverable to assess the completed work.
4. For Task 2, review the meeting invite print before the Action Plan to confirm that the meeting agenda aligns with the resulting action items.
5. For Task 3, review the Supply Chain Report analysis before the Supply Chain Issue Analysis Report, since the report is based on the Excel data insights.
6. For Task 4, review the Supply Chain Issue Compliance Report presentation last, as it consolidates findings from previous tasks into a stakeholder-ready format.
